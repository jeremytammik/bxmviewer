# bxmviewer

Web viewer for BXM models converted to glTF, with plan-view JPGs shown in context.

Open the live viewer: https://jeremytammik.github.io/bxmviewer/

Models: `?model=model6282`, `renov`, `warehouse`, `modelfile`.

This repository is a published build; the source lives in the private BxmToGltfSuite repository.
Three.js (MIT) is vendored under `viewer/vendor/three`.
